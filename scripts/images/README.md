# توليد صور المقالات وصور المشاركة

- `render.mjs`: أغلفة المقالات والإنفوجرافيك → `public/images/articles/` (webp بمقاسين).
- `og.mjs`: صور المشاركة (واتساب/فيسبوك) لكل خدمة ومنطقة ومقال → `public/og/` + يحدّث `src/lib/og-images.ts`.
- البيانات: `data.mjs` (المقالات) وأعلى `og.mjs` (الخدمات والمناطق)، والرسومات في `art.mjs`.

عند إضافة مقال جديد بملف: أضفه لـ `data.mjs` وشغّل السكربتين (يحتاج Playwright + Chromium + إنترنت لخط Google).
